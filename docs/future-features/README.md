# Future Features & Ideas

This folder contains planned enhancements and feedback for the Arabic Verb Trainer.

## Planned Features

### On-Screen Arabic Keyboard ([arabic-keyboard-plan.md](./arabic-keyboard-plan.md))
Add a clickable on-screen keyboard to make it easier for students to type diacritics without a physical Arabic keyboard. This is a low-to-moderate difficulty additive UI feature.

**Status**: Planned  
**Priority**: Medium (addresses usability friction in feedback-notes)
